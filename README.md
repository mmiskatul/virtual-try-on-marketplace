# Central Fashion Marketplace (Next.js 14 + Tailwind CSS)

Customer-facing multi-brand luxury fashion marketplace with integrated AI Virtual Try-On Studio.

## Technology Stack
- Framework: Next.js 14 (App Router)
- Language: TypeScript
- Styling: Tailwind CSS & Haute Couture Dark Aesthetic
- Icons: Lucide React

## Standalone Execution

### 1. Install Dependencies & Configure Environment
```bash
npm install
cp .env.example .env
```

### 2. Development Mode
```bash
npm run dev
# Marketplace runs at http://localhost:3000
```

### 3. Production Build & Start
```bash
npm run build
npm start
```

## Features
- **Discovery & Catalog:** Search, category chips, brand filter, price sort, try-on eligible filter
- **Brand Boutique Profiles:** Discover participating independent fashion brands
- **Interactive AI Try-On Studio:** Photo upload, pose validation, neural synthesis with side-by-side comparison
- **Shopping Bag & Single-Seller Checkout:** Segregates items by brand seller, enforces single-seller checkout rule
